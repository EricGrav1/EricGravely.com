## FUNNEL LOGIC (Critical — build this correctly)

When a user submits the lead magnet form:
1. Client-side: disable button, show spinner
2. POST to /api/subscribe with { firstName, email, tag: "lead-magnet" }
3. Server-side API route:
   - Validate inputs
   - Call ConvertKit API: add subscriber + apply tag
   - Call Resend API: send transactional email with lead magnet link
   - Return success/error JSON
4. Client: on success → redirect to /thank-you
5. Client: on error → show inline error message (do NOT clear the form)

Store API keys in .env.local:
- CONVERTKIT_API_KEY
- CONVERTKIT_FORM_ID
- RESEND_API_KEY
- YOUTUBE_API_KEY (optional, can use static config fallback)
